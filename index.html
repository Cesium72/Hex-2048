What is this?

This is like the classic number game, 2048, but instead of a square, it's a hexagon! When you make a move, (for example, right), all the tiles will move as far to the right as they can. If two tiles with the same number hit each other, they combine into the next one up! If you haven't played classic 2048 before, go to play2048.co to try it first.
